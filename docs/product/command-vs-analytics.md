# Command vs MesaAnalytics

Hard boundary. Prevents two overlapping executive dashboards.

| | **Command** | **MesaAnalytics** |
| --- | --- | --- |
| Question | What needs my attention **right now**? | How did we perform **over time**? |
| Horizon | Today / this shift / open exceptions | Weeks, months, quarters |
| Interaction | Act: approve, assign, drill to source | Explore: filter, compare, export |
| Data | Live operational exceptions | Aggregated, historical, cross-plant |
| Included | Yes, with any entitled product (MD) | Paid add-on (future) |
| Phase 1 manuals | Full static UI (2 screens) | IA + placeholder only |

## Command examples

- QA hold blocking dispatch
- Plan behind schedule
- Quote awaiting approval
- Evidence ready for MesaBook posting (Needs mapping)

## MesaAnalytics examples

- Scrap trend by machine
- OTIF by customer
- Margin by product family
- Cross-plant utilization

## Sales line

> Command keeps the owner in control today. MesaAnalytics explains performance over time. Different questions, different products.
