# Expansion playbook (sales and CS)

## Triggers to expand

| Customer signal | Recommend |
| --- | --- |
| “We need invoices / stock value / GST” | Add **MesaBook** |
| “Quotes are in Excel / WhatsApp” | Add **MesaSell** |
| “Vendors keep calling for PO status” | Add **Connect** (requires MesaBook) |
| “MD wants trends, not just today’s fires” | Add **MesaAnalytics** |
| “We bought Plant Start and Commercial Start separately” | Move to **Manufacturing Suite** |

## Objections

| Objection | Response |
| --- | --- |
| “We need full ERP on day one” | Land Plant Start; expand when shop floor is stable. Suite without adoption fails. |
| “Finance will stop the floor” | MesaPlant and MesaBook stay independent. Handoffs are optional and visible. |
| “Command is enough reporting” | Command is for today. Analytics is for trends. See [command-vs-analytics.md](command-vs-analytics.md). |
| “Suppliers need access now” | Connect requires MesaBook for vendor/PO truth. Plant-only pilots use employee workflows. |

## Talk track (land → expand → retain)

1. **Land:** Plant Start for Apex Polymers Plant 1 — operators, QA, dispatch.
2. **Expand:** When MD asks for one commercial number, enable MesaBook / MesaSell.
3. **Retain / platform:** Multi-plant + Connect + MesaAnalytics when audit and vendors demand it.

## Org Control upsell surface

Organization Control shows **Active products** and **Available products** (grayed: Contact MesaWorks to enable). MesaWorks flips entitlements in Platform Control.
